# 简历项目描述（升级后，需结合个人理解使用）

**面向企业研发的 API 知识库与 Agent 工作流平台**

技术栈：Vue 3 / TypeScript / NestJS / Prisma / PostgreSQL / pgvector / LLM Tool Calling

基于 Hoppscotch 二次开发，面向研发团队接口资料分散、接口发现困难和测试数据准备繁琐的问题，构建团队 API 知识库与智能研发助手。

- 构建关键词与向量双路检索，通过加权 RRF 融合排名并按接口 ID 去重；将接口结构及字段说明注入模型上下文，实现带来源的接口问答。
- 将接口搜索、详情读取及 Mock 校验封装为模型工具，实现受步数限制的 Agent 调用循环；将结构校验错误反馈给模型，支持候选数据修正与执行记录回看。
- 设计后台向量同步状态机，通过内容哈希、源版本、任务租约与条件写回处理并发更新；实现失败重试、手动补偿与过期向量过滤。
- 接入团队权限校验，限制检索与工具调用的数据范围；统一 JSON 模板生成链路，保留显式业务约束，补充检索、权限、生成校验及任务执行的回归测试。

不要写“企业已上线”“百万级检索”“准确率提升 xx%”等未验证指标。开源原生能力、原毕业设计贡献和本次辅助升级应在面试时如实区分。
